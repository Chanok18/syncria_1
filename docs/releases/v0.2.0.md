# Release Notes - Syncria v0.2.0

## Authentication System

**Fecha de release**: 2026-07-27
**Tipo**: Feature release
**Sprint**: 02

---

## Resumen

Syncria v0.2.0 entrega un **sistema completo de autenticacion** que permite a los usuarios registrarse, iniciar sesion, acceder a pagas protegidas y cerrar sesion. Este es el primer release con funcionalidad de negocio real.

## Que incluye

### Registro de Usuario
- Formulario de registro con nombre, email y contrasena
- Validacion de email unico en el servidor
- Contrasena minima de 8 caracteres
- Hashing de contrasenas con BCrypt
- Redireccion automatica al dashboard despues del registro

### Inicio de Sesion
- Formulario de login con email y contrasena
- Generacion de JWT con expiracion de 24 horas
- Mensaje de error claro para credenciales invalidas
- Redireccion automatica al dashboard despues del login

### Rutas Protegidas
- Todas las rutas principales requieren autenticacion
- Redireccion automatica a /login si no hay token
- Token enviado automaticamente en cada request via Axios interceptor

### Cierre de Sesion
- Boton de logout en el header
- Limpieza del token del localStorage
- Redireccion a la pagina de login

### Seguridad
- JWT (JSON Web Tokens) para autenticacion stateless
- Spring Security con filtro JWT personalizado
- CORS configurado para desarrollo local
- Password hashing con BCrypt
- Endpoints publicos: /auth/register, /auth/login, /health
- Endpoints protegidos: todos los demas

## API Endpoints

| Metodo | Ruta | Auth | Descripcion |
|--------|------|------|-------------|
| GET | /api/v1/health | No | Health check |
| POST | /api/v1/auth/register | No | Registro de usuario |
| POST | /api/v1/auth/login | No | Login, retorna JWT |
| GET | /api/v1/auth/me | Si | Informacion del usuario actual |

### Ejemplo de Registro

```bash
curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "vet@clinica.com",
    "password": "password123",
    "fullName": "Dr. Garcia"
  }'
```

**Response (201 Created)**:
```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "email": "vet@clinica.com",
  "fullName": "Dr. Garcia",
  "role": "USER"
}
```

### Ejemplo de Login

```bash
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "vet@clinica.com",
    "password": "password123"
  }'
```

**Response (200 OK)**:
```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "email": "vet@clinica.com",
  "fullName": "Dr. Garcia",
  "role": "USER"
}
```

### Ejemplo de Request Autenticado

```bash
curl -X GET http://localhost:8080/api/v1/auth/me \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

**Response (200 OK)**:
```json
{
  "token": null,
  "email": "vet@clinica.com",
  "fullName": "Dr. Garcia",
  "role": "USER"
}
```

## Como ejecutar

### Backend
```bash
cd backend
./mvnw spring-boot:run    # Unix
mvnw.cmd spring-boot:run  # Windows
```

### Frontend
```bash

npm install
npm run dev
```

